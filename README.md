
# Getting Started with Data

## 1. Deskripsi Sertifikat

Repository ini merupakan dokumentasi sertifikat **Getting Started with Data** yang diperoleh melalui program pembelajaran IBM SkillsBuild.

Pembelajaran ini menjadi bagian dari pengembangan kompetensi dan pemahaman dasar mengenai bidang data, khususnya sebagai landasan untuk mempelajari Data Analytics.

Dokumentasi ini dibuat sebagai bagian dari portofolio pengembangan diri untuk membangun pengetahuan dan keterampilan yang relevan dengan bidang Data Analyst.

## 3. Kompetensi yang Dipelajari

Pembelajaran Getting Started with Data memberikan pengenalan terhadap bidang data sebagai dasar untuk memahami bagaimana data dapat digunakan dalam menghasilkan informasi.

Beberapa aspek pemahaman yang relevan dengan pembelajaran ini meliputi:

- **Data Fundamentals:** Memahami konsep dasar dan peran data.
- **Data Awareness:** Mengenal pentingnya data dalam mendukung pengambilan keputusan.
- **Data Analytics Foundation:** Membangun pemahaman awal mengenai bidang analisis data.
- **Data-Oriented Thinking:** Mengenal pendekatan berbasis data dalam memahami permasalahan.

## 4. Relevansi dengan Bidang Data Analyst

Pembelajaran ini memiliki relevansi sebagai dasar pengembangan kompetensi di bidang Data Analyst.

Dalam proses analisis data, pemahaman mengenai data menjadi landasan sebelum melakukan pengumpulan, pemeriksaan, pengolahan, analisis, hingga penyajian informasi.

Pengetahuan tersebut selanjutnya dikembangkan melalui pembelajaran dan praktik menggunakan beberapa tools berikut:

| Tools | Penerapan |
|---|---|
| Microsoft Excel | Pengolahan data, formula, PivotTable, dan visualisasi |
| Python | Data cleaning, data processing, dan Exploratory Data Analysis |
| SQL | Pengambilan dan pengelolaan data menggunakan query |
| Power BI | Pembuatan dashboard dan visualisasi data |

## 6. Pengembangan Kompetensi Selanjutnya

Pembelajaran ini menjadi salah satu langkah awal dalam mengembangkan kompetensi di bidang Data Analytics.

Pengembangan selanjutnya difokuskan pada penerapan keterampilan melalui proyek praktik, meliputi:

- Data Cleaning and Preparation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Dashboard Development
- Data Interpretation and Reporting

Melalui pembelajaran dan proyek praktik tersebut, kemampuan dalam mengolah, menganalisis, dan menyajikan data diharapkan dapat terus berkembang.
